# Hub Otaku ∞

Portal definitivo da cultura japonesa — Animes, Mangás, Jogos, Notícias e IA Sakura.

🔗 **Site ao vivo**: [https://hubotaku.mooo.com](https://hubotaku.mooo.com)

---

## ✨ Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| 🎌 **Animes** | Catálogo com dados reais da API Jikan (MyAnimeList) |
| 📖 **Mangás** | Top mangás com notas, capítulos e status |
| 🎮 **Jogos** | Jogos otaku com plataformas e trailers |
| 📰 **Notícias** | Notícias atualizadas sobre cultura japonesa |
| 🤖 **IA Sakura** | Assistente virtual com respostas inteligentes |
| ❤️ **Favoritos** | Guarda favoritos no navegador |
| 📋 **Watchlist** | Lista de conteúdo para ver mais tarde |
| 🎲 **Roleta** | Descubra conteúdo aleatório |
| ⚙️ **Painel Admin** | Adicione, edite e remova conteúdo |
| 🌙 **Tema Claro/Escuro** | Alterne entre temas |
| 📲 **PWA** | Instale como app no telemóvel/desktop |

---

## 🚀 Como usar no GitHub Pages

1. **Faz fork** ou cria um novo repositório
2. **Faz upload** de todos os ficheiros desta pasta para a raiz do repo
3. Vai a **Settings → Pages** e ativa GitHub Pages
4. Configura o domínio personalizado: `hubotaku.mooo.com`
5. Adiciona um ficheiro `CNAME` com o conteúdo: `hubotaku.mooo.com`
6. Pronto! O site está online em segundos

## 🔧 APIs Utilizadas

- **Jikan API** — Dados reais de animes e mangás do MyAnimeList
- **Pollinations AI** — IA Sakura (gratuita, sem API key)
- **YouTube Embed** — Trailers e vídeos

---

## 🎨 Personalização

No painel Admin podes:
- Alterar a cor de destaque (Rosa, Ciano, Roxo, Dourado, Verde)
- Adicionar/editar/remover conteúdo
- Exportar/importar dados em JSON

---

## 📱 PWA

O site funciona como uma app nativa:
- Instala no Android/iOS ("Adicionar ao ecrã inicial")
- Funciona offline (Service Worker)
- Notificações push (em breve)
